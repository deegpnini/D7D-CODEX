# D7D-CODEX

Sistema orquestral D7D — Amor Ágape 100%

## Sobre o projeto

O D7D-CODEX é um sistema de orquestração que integra múltiplos
componentes de IA em um ecossistema coeso.

## Estrutura do projeto

```
D7D-CODEX/
├── config/
│   └── codex.json
├── web/
│   ├── dashboard.html
│   ├── dashboard_orquestra.html
│   └── index.html
├── backups/
├── orquestra.py
├── sistema_completo.py
├── sistema_final.py
├── xp_system.py
├── projetos.py
├── test_report.py
├── deploy_codix.sh
├── checklist.txt
└── README.md
```

## Como executar

```bash
python3 sistema_completo.py
```
